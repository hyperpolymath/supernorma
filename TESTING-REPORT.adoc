== Known gaps to a green `deno task test`

1. The ReScript sources must be compiled so `*_test.res.js` files exist —
   Deno cannot execute `.res` directly. `deno task build` performs the
   compile (currently via `npx rescript`).
2. `src/Mod.res` exports were reconciled with `Mod_test.res` on 2026-07-02
   (added `pensionRecord`, `version`, `projectName`, `calculateNetIncome`,
   `isSurplus`); the suite has not yet been executed in an environment with
   Deno available.
3. `tests/fuzz/` contains only a placeholder.

== How to run

[source,bash]
----
deno task build   # compile ReScript -> *.res.js
deno task test    # run unit + integration suites
----

Record real pass/fail counts here after each run; do not update this report
without running the suite.
